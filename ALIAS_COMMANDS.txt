🚀 QUICKEST WORKFLOW (3 commands):

  1. find-port
     → Find your ESP32's COM port
     → Shows which USB port is your ESP32

  2. test-upload COM3
     → Test with the blink sketch
     → Replace COM3 with your actual port

  3. upload my_sketch.ino COM3
     → Upload your code to ESP32
     → That's it!

═══════════════════════════════════════════════════════════════════════════════

📋 ALL COMMANDS:

  find-port [NO ARGS]
  ├─ Usage: find-port
  ├─ Shows connected COM ports
  └─ Find the one with (USB) - that's your ESP32!

  upload [SKETCH.INO] [COM_PORT]
  ├─ Usage: upload my_sketch.ino COM3
  ├─ Or:    upload my_sketch.ino (auto-detect)
  └─ Uploads your sketch

  test-upload [COM_PORT]
  ├─ Usage: test-upload COM3
  ├─ Or:    test-upload (auto-detect)
  └─ Tests with the blink sketch

  compile [SKETCH_FOLDER]
  ├─ Usage: compile C:\path\to\sketch
  ├─ Compile only (no upload)
  └─ Good for checking errors

  search-lib [KEYWORD]
  ├─ Usage: search-lib WiFi
  ├─ Searches for available libraries
  └─ Example: search-lib Adafruit

  install-lib [LIBRARY_NAME]
  ├─ Usage: install-lib "WiFi"
  ├─ Install a library
  └─ Use quotes if name has spaces

  list-libs [NO ARGS]
  ├─ Usage: list-libs
  ├─ Shows all installed libraries
  └─ See what you have available

  help-arduino [NO ARGS]
  ├─ Usage: help-arduino
  ├─ Shows this help screen
  └─ Quick reference
