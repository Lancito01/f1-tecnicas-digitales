🔍 TROUBLESHOOTING:

Problem: Port not found
→ Run: find-port
→ Check Device Manager for USB devices
→ Verify USB cable works

Problem: Timeout during upload
→ Try holding BOOT button on ESP32
→ Try different USB port on computer

Problem: "Port in use"
→ Close Arduino IDE if open
→ Close any Serial Monitor windows
